# 書槑子青年坊官網 — 規格書

2026/10/10 決定（與使用者討論）：

## 1. 目標

- 取代舊的 Webnode 官網（免費版，日期要手動改、常常過期；網址有範本留下的怪名字）。
- 介紹書槑子青年坊與三個主要活動（槑子的靈魂健身房、槑青韜課館、植素園工作坊）＋志工。
- **近期活動自動從行事曆抓**，不用再手動改日期；每個活動點了直接到行事曆報名。
- 和行事曆用同一套顏色、字體，看起來是同一個品牌。手機優先。

## 2. 決定

| 項目 | 決定 |
| --- | --- |
| 網址 | 先用免費的 GitHub Pages（例：bailixiao.github.io/shumeizi/），之後要買網域再換 |
| 誰來改 | 活動自動；介紹文字、照片很少改，要改時找 Claude |
| 架構 | 官網、行事曆分開兩個網站，互相連結 |
| 舊官網 | Webnode 免費版不能轉址：新官網上線後，請舊官網管理者加「我們搬家了 →」或關站 |

## 3. 頁面

| 檔名 | 頁面 | 內容 |
| --- | --- | --- |
| index.html | 首頁 | 標語、簡介、三個活動介紹卡、開放中的團購（自動）、聯絡我們 |

- 每頁上方：標誌＋選單；下方：官方 LINE、植素園 HAPPY 購、行事曆連結。
- **下拉式選單（2026/10/13，參考一貫道青年團 fycd.org 手機版）**：首頁｜關於我們 ▸（關於我們、回憶與回饋）｜槑子活動 ▸（靈魂健身房、槑青韜課館、志工）｜植素園工作坊 ▸（植素園工作坊、團購、出攤預告、HAPPY 購團購社群）｜聯絡我們 ▸（聯絡方式、官方 LINE、行事曆報名）（2026/10/13：上面那排的「📅 行事曆」也拿掉，只留在聯絡我們裡；右上角的「📅 看行事曆、報名」按鈕加回來，在「選單」旁邊，手機寫「📅 行事曆」）。手機：右上「☰ 選單」往下展開，大項點了展開子項目（目前這頁所在的大項先展開）；電腦：一排，大項滑過或點了跳出子選單。原本右上的「看行事曆、報名」按鈕拿掉（點進來先看到官網），行事曆放在選單；首頁的「看近期活動、報名」按鈕、「近期活動」區塊、頁尾的「看行事曆、報名」也先拿掉（2026/10/13，使用者：先不用一進去就看到行事曆）；活動卡片的報名照樣連到行事曆。大項用 <details>，沒有 JavaScript 也能用。
- 舊網址的對照：/關於我們/ → about.html、/我們的葡萄酒/（植素園）→ zhisu.html、/聯絡資訊/（靈魂健身房）→ gym.html、/槑青韜課館/ → taoke.html、/槑子回憶/ → stories.html。

## 4. 自動的資料（行事曆 API）

- 讀：`GET {API}?action=getEvents&from=今天&to=今天+60天`、`GET {API}?action=getShop`（只讀，不送任何個資）。
- 類別對照：道務＝靈魂健身房、教育＝槑青韜課館、植素＝植素園工作坊、勤務＝志工。
- 連結：活動 → `{行事曆}#/duty/{id}?date={日期}`。團購：賣貨便的（有 link）直接連到賣貨便賣場（開新分頁）；行事曆下單的連到行事曆的團購頁 `{行事曆}#/shop/{團購ID}`；有封面（cover）就顯示封面，沒有就顯示商品照片。
- 讀不到（沒網路、API 掛了）：顯示「到行事曆看最新活動」按鈕，頁面其他部分照常。
- 本機（localhost）：API 用行事曆示範版 `http://localhost:5175/api`、行事曆連 `http://localhost:5175/`；正式：`https://shumeizi-api.duty-calendar-worker.workers.dev/`、`https://bailixiao.github.io/shumeizi-calendar/`。

## 5. 照片與個資

- 舊官網的照片先從網站抓（壓縮過的）；原圖、標誌原檔請團隊提供後替換。
- 有人臉的照片（韜課館宣傳圖、一週年合照、擺攤照、回饋照片）：舊官網本來就公開這幾張，2026/10/10 使用者決定上線時照放。**之後新增有人臉的照片仍要本人同意**；還沒同意的先放 `_old/`（不進 git），`node tools/build.js --publish` 會擋下。
- 舊官網的 Webnode 範本圖庫照片（cloudfront 那幾張大圖）不沿用。
- 回饋不寫名字（舊官網的「陳Ｏ妤」改成「槑友・科技業」）。
